## 앱으로 설치하기

- **PC 크롬·엣지**: 시작 화면의 "📲 앱으로 설치" 버튼, 또는 주소창 오른쪽 설치 아이콘
- **안드로이드 크롬**: ⋮ 메뉴 → 앱 설치
- **아이폰·아이패드 사파리**: 공유 버튼 → 홈 화면에 추가

설치하면 바탕화면(홈 화면)에 단팥 아이콘이 생기고, 인터넷이 없어도 플레이할 수 있어요.
